---
block: dsgvoBanner
---

The DSGVO Banner block shows the cookie consent settings of the site, so visitors can choose which trackers and embedded services they allow. It is used on privacy settings pages.

### Stored data

The block stores only its type. It has no settings of its own: the choices shown by the block, the modules and the privacy page link come from the site configuration, not from the block data.

### Example

```json
{
  "@type": "dsgvoBanner"
}
```
